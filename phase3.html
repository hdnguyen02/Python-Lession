Pygame là gì?
SDL · cross-platform · cài đặt · tổng quan module
▼
Lý thuyết

Pygame là một tập hợp các module Python được xây dựng trên thư viện SDL (Simple DirectMedia Layer) — một thư viện C cấp thấp xử lý đồ họa, âm thanh, bàn phím, chuột. Pygame bọc SDL lại để Python có thể sử dụng dễ dàng.

💡
Pygame không phải game engine. Nó chỉ cung cấp công cụ cấp thấp: vẽ pixel, phát âm thanh, đọc input. Bạn phải tự xây dựng game loop, physics, collision — đó là lý do dùng Pygame để học: bạn hiểu từng thứ hoạt động thế nào.

Cửa sổ game & Game Loop
pygame.init · display.set_mode · Clock · FPS · event.get · QUIT
▼
Lý thuyết — Khung xương của mọi game Pygame

Mọi game Pygame đều có cùng một cấu trúc: khởi tạo → tạo cửa sổ → game loop. Game loop chạy lặp đi lặp lại 60 lần/giây, mỗi vòng làm 3 việc: xử lý sự kiện, cập nhật trạng thái, vẽ lại màn hình.

Python Khung xương game loop cơ bản 
import pygame
import sys

pygame.init()                                    # Bật tất cả module pygame
window = pygame.display.set_mode((500, 700))    # Tạo cửa sổ 500×700 px
pygame.display.set_caption("Flappy Bird")       # Tiêu đề cửa sổ
clock = pygame.time.Clock()                     # Đối tượng kiểm soát FPS

while True:
    clock.tick(60)                               # Giới hạn 60 frame/giây

    # 1. Xử lý sự kiện
    for event in pygame.event.get():
        if event.type == pygame.QUIT:             # Người dùng bấm X cửa sổ
            pygame.quit()
            sys.exit()

    # 2. Cập nhật trạng thái game (physics, logic)
    window.fill((135, 206, 235))               # Tô nền màu xanh trời

    # 3. Vẽ lại màn hình
    pygame.display.update()                     # Refresh cửa sổ

Trong project Flappy Bird, phần này được đóng gói thành Screen class và Control class:

Python Screen.py 
from pygame import display

class Screen:
    def __init__(self, size):
        self.width, self.height = size
        self.size = size
        self.window = display.set_mode(self.size)  # Tạo cửa sổ

    def draw(self, surface, coordinate):
        self.window.blit(surface, coordinate)      # Vẽ surface lên cửa sổ

    def midleXScreen(self, surface):
        w = surface.get_width()
        return self.width / 2 - w / 2           # Căn giữa ngang
⚠️
clock.tick(60) phải gọi đầu mỗi vòng loop, không phải cuối. Nó ngủ đúng số ms cần thiết để đảm bảo 60 FPS — nếu frame tính toán nhanh thì ngủ lâu hơn, nếu chậm thì không ngủ.
HàmTác dụng

Hai khái niệm quan trọng nhất trong Pygame: Surface (tấm ảnh/canvas) và Rect (vị trí + kích thước). Mọi thứ bạn vẽ đều là blit một Surface lên một Rect.

Python Surface và Rect 
# Surface = tấm canvas chứa pixel
surface = pygame.image.load('image/bird/0.jpg')  # load từ file

# Rect = hình chữ nhật xác định vị trí
rect = surface.get_rect(topleft=(140, 200))    # góc trên-trái tại (140, 200)
rect = surface.get_rect(center=(250, 350))     # tâm tại (250, 350)
rect = surface.get_rect(midleft=(370, 180))    # cạnh trái-giữa tại (370, 180)

# Di chuyển rect (không di chuyển surface)
rect.x -= 2           # dịch sang trái 2px
rect.centery += 0.25  # dịch xuống 0.25px (gravity!)

# Vẽ surface lên cửa sổ tại vị trí rect
window.blit(surface, rect)

# Kiểm tra va chạm giữa 2 rect
if rect_bird.colliderect(rect_pipe):
    print("Va chạm!")

# Lấy kích thước surface
width, height = surface.get_size()
w = surface.get_width()
h = surface.get_height()

Python Utilitie.py — các helper load ảnh 
from pygame import image, transform

class Utilitie:

    # Load ảnh và scale về kích thước cố định
    @staticmethod
    def surfaceSize(path, size):
        surface = transform.scale(image.load(path), size)
        return surface

    # Load ảnh và thu nhỏ theo tỷ lệ (chia scale lần)
    @staticmethod
    def surfaceScale(path, scale):
        surface = image.load(path)
        width, height = surface.get_size()
        surface = transform.scale(surface, (width / scale, height / scale))
        return surface

# Ví dụ trong Pipe.py — load cột và lật ngược để tạo cột trên
SF_COL_BOTTOM = transform.scale(image.load('image/pipe.jpg'), (60, 360))
SF_COL_TOP    = transform.flip(SF_COL_BOTTOM, False, True)  # lật dọc
HàmTham sốTác dụng

Bird — Trọng lực, Nhảy & Animation

▼
Lý thuyết — Vật lý đơn giản

Bird dùng mô hình vật lý đơn giản: mỗi frame, movement tăng thêm GRAVITY (rơi xuống), tọa độ Y tăng theo movement. Khi nhảy, movement bị reset về -SPEED (bắn lên).

Python Bird.py — Trọng lực và nhảy 
class Bird:
    GRAVITY = 0.25   # gia tốc rơi mỗi frame
    SPEED   = 5      # tốc độ nhảy lên
    X       = 140    # tọa độ X cố định (bird không di chuyển ngang)

    def __init__(self, screen):
        self.movement = 0          # vận tốc dọc hiện tại
        self.rect = surface.get_rect(center=(Bird.X, 200))

    def handleJump(self):
        self.movement = -Bird.SPEED  # đặt vận tốc âm = bay lên

    def updateHandleGame(self):
        self.movement += Bird.GRAVITY  # trọng lực kéo xuống mỗi frame
        self.rect.centery += self.movement
        self.screen.draw(self.surface, self.rect)

Animation — Bird có 17 frame ảnh, chuyển đổi mỗi 16ms bằng USEREVENT:

Python Bird.py — Animation với USEREVENT 
from pygame import USEREVENT, time

class Bird:
    eventBirdFly = USEREVENT + 5              # tạo event ID riêng
    time.set_timer(eventBirdFly, 16)          # gửi event này mỗi 16ms

    def addListSurface(self):
        for i in range(17):                     # 17 frame ảnh
            temp = Utilitie.surfaceScale(f'image/bird/{i}.jpg', 17)
            self.list_surface.append(temp)

    def eventFly(self, event):
        if event.type == Bird.eventBirdFly:
            self.index_surface = (self.index_surface + 1) % 17  # vòng qua 17 frame
            self.surface = self.list_surface[self.index_surface]

Floor — Sàn cuộn vô hạn
Tiling 3 bản · cuộn theo SPEED · reset khi ra ngoài màn hình
▼
Lý thuyết

Sàn cuộn vô hạn bằng kỹ thuật tiling: vẽ 3 bản sàn nối tiếp nhau, dịch sang trái mỗi frame. Khi bản đầu ra ngoài màn hình thì reset x về 0 — tạo hiệu ứng vô hạn.

Python Floor.py 
class Floor:
    surface = image.load('image/floor.jpg')
    width, height = Surface.get_size(surface)
    SPEED = 2

    def updateHandleGame(self, isPlay):
        # Vẽ 3 bản sàn nối tiếp
        rect01 = self.surface.get_rect(bottomleft=(self.x,              self.screen.height))
        rect02 = self.surface.get_rect(bottomleft=(self.x + self.width,   self.screen.height))
        rect03 = self.surface.get_rect(bottomleft=(self.x + self.width*2, self.screen.height))
        self.screen.draw(self.surface, rect01)
        self.screen.draw(self.surface, rect02)
        self.screen.draw(self.surface, rect03)

        if self.x <= -Floor.width:
            self.x = 0   # reset khi bản đầu ra hết màn hình
        if isPlay:
            self.x -= Floor.SPEED  # chỉ di chuyển khi đang chơi

Pipe — Cột chướng ngại vật

Lý thuyết

Mỗi cặp cột gồm 1 cột dưới (bottom) và 1 cột trên (top = lật ngược), cách nhau 1 khoảng BLANK = 160px. Project dùng danh sách 3 cặp cột, khi cặp đầu ra khỏi màn hình thì xóa và thêm cặp mới vào cuối.

Python Pipe.py 
class Pipe:
    WIDTH, HEIGHT = 60, 360
    SF_COL_BOTTOM = transform.scale(image.load('image/pipe.jpg'), (WIDTH, HEIGHT))
    SF_COL_TOP    = transform.flip(SF_COL_BOTTOM, False, True)  # lật dọc
    BLANK    = 160  # khoảng hở giữa 2 cột (px)
    DISTANCE = 220  # khoảng cách giữa 2 cặp cột
    SPEED    = 2

    @staticmethod
    def createRectCol(x, y):
        return {
            "pass":   False,          # đã qua bird chưa?
            "top":    Pipe.SF_COL_BOTTOM.get_rect(topleft=(x, y)),
            "bottom": Pipe.SF_COL_TOP.get_rect(topleft=(x, y + Pipe.BLANK + Pipe.HEIGHT))
        }

    def updateHandleGame(self, isPlay):
        self.draw_cols()
        if not isPlay: return
        for rCol in self.__rCols:
            rCol["top"].x    -= Pipe.SPEED   # di chuyển sang trái
            rCol["bottom"].x -= Pipe.SPEED
        if self.__rCols[0]["top"].x < -Pipe.WIDTH:  # cặp đầu ra ngoài
            self.__rCols.pop(0)                    # xóa đi
            x = self.__rCols[1]["top"].x + Pipe.DISTANCE
            self.__rCols.append(Pipe.createRectCol(x, self.__randomYCol()))

Python Bird.py — Va chạm 
def isCollision(self, rCols):
    # Va chạm sàn hoặc mép trên cửa sổ
    if self.rect.y <= 0 or self.rect.y >= self.screen.height - Floor.height:
        return True
    # Va chạm cột
    for rCol in rCols:
        if self.rect.colliderect(rCol["bottom"]) or self.rect.colliderect(rCol["top"]):
            return True
    return False

def computedScore(self, rCols, xBird, isSound):

            if isSound:
                Achievement.soundPass.play()
            self.score += 1
            rCol["pass"] = True   # đánh dấu đã tính

def surfaceFont(path_font, size_font, title, color):

# Button — kiểm tra click chuột
class Button:
    def checkClick(self, pos):
        x_pos, y_pos = pos
        return (x_pos in range(self.rect.left, self.rect.right) and
                y_pos in range(self.rect.top,  self.rect.bottom))

# Input — ô nhập text với cursor
class Input:
    def handleEvent(self, event):
        if self.select and event.type == KEYDOWN:
            self.text = self.text[:-1]         # bỏ cursor '_' hiện tại
            if event.key == K_BACKSPACE:
                self.text = self.text[:-1] + '_'  # xóa ký tự + thêm cursor
            elif event.unicode.isalpha():
                self.text += event.unicode + '_'    # gõ chữ + cursor

    def draw(self):
        draw.line(self.screen.window, self.color,
                   (self.x, self.y), (self.x + self.width, self.y), self.border)

Lý thuyết — State Machine đơn giản

Game có 3 trạng thái: Start → Playing → GameOver. Trong project, flag isPlay và 3 method riêng biệt (startGame, handlGame, finishGame) đảm nhận từng state.

Python Control.py — finishGame animation 
def finishGame(self):
    # Các biến theo dõi vị trí animation
    start_y_table  = 700  # bảng điểm bắt đầu ngoài màn hình (dưới)
    end_y_table    = 170  # vị trí đích của bảng điểm
    y_start_go     = 0    # game over title từ trên xuống
    y_end_go       = 100

    while True:
        self.clock.tick(60)
        for sub in pygame.event.get():
            if self.staticView.btnReplayFinish.checkClick(pygame.mouse.get_pos()):
                self.resetGame()
                self.handlGame()

        # Animate game over title rơi xuống
        y_drawn_go = min(y_start_go, y_end_go)
        window.blit(sf_game_over, (centerx_go, y_drawn_go))
        y_start_go += 20   # di chuyển 20px/frame cho đến khi chạm y_end_go

        # Animate bảng điểm trượt lên từ dưới
        y_drawn_table = max(start_y_table, end_y_table)
        window.blit(sf_table, (centerx_table, y_drawn_table))
        start_y_table -= 30
💡
Kỹ thuật animation đơn giản: Biến y bắt đầu ngoài màn hình, mỗi frame tăng/giảm một lượng cố định. Dùng min()/max() để clamp tại vị trí đích. Không cần thư viện animation phức tạp.

open · readlines · sort · writelines · Top 5 logic

Lý thuyết

Bảng xếp hạng lưu Top 5 vào file top.txt, mỗi dòng là tên-điểm. Mỗi khi game kết thúc, nếu điểm mới vào Top 5 thì cập nhật file.

Python Achievement.py — Đọc/ghi bảng xếp hạng 
def readFileTop(self):
    file_top = open('top.txt', 'r')
    for line in file_top:
        name, score = line.rstrip().split('-')
        self.top_5_user.append(dict(name=name, core=int(score)))
    file_top.close()

def handleDie(self):
    # Chỉ lưu nếu điểm mới vào Top 5
    if self.name and self.score > self.top_5_user[4]["core"]:
        self.top_5_user.append(dict(name=self.name, core=self.score))
        self.top_5_user.sort(key=lambda u: u["core"], reverse=True)
        self.top_5_user.pop()   # giữ đúng 5 người
        self.writeFileTop()

def writeFileTop(self):
    file = open('top.txt', 'w')
    temp = [x['name'] + '-' + str(x['core']) + '\n' for x in self.top_5_user]
    file.writelines(temp)
    file.close()
