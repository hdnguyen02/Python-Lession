Tuần 5 · Git — Lưu lại lịch sử code
📸
Git là gì?
Hiểu ý nghĩa của Git · cài đặt · cấu hình tên và email
▼
Lý thuyết

Hãy tưởng tượng bạn đang vẽ một bức tranh. Mỗi lần vẽ được một phần đẹp, bạn muốn chụp ảnh lại để nếu vẽ hỏng thì còn quay lại được. Git làm đúng điều đó với code — nó giúp bạn lưu lại từng "bản chụp" của code theo thời gian.

💡
Git ≠ GitHub. Git là công cụ chạy trên máy tính của bạn. GitHub là trang web để lưu code lên mạng (như Google Drive nhưng dành cho code).

Cài đặt Git — tải về tại git-scm.com rồi cài như bình thường. Sau khi cài xong, mở Terminal và gõ lệnh sau để kiểm tra:

Terminal 
git --version
# In ra: git version 2.x.x  → cài thành công!

Cấu hình tên và email — Git cần biết bạn là ai để ghi vào lịch sử:

Terminal 
git config --global user.name "Tên của bạn"
git config --global user.email "email@example.com"

# Kiểm tra lại
git config --global user.name
# In ra: Tên của bạn
🎯
Chỉ cần làm bước cấu hình một lần duy nhất trên máy tính của bạn. Sau đó Git sẽ nhớ mãi.

Quy trình làm việc với Git có 3 khu vực:

🗺️
Working folder (thư mục đang làm) → Staging area (chuẩn bị chụp ảnh) → Repository (kho lưu ảnh)

Bước 1 — Khởi tạo Git trong thư mục dự án:

Terminal 
# Vào thư mục dự án của bạn
cd ten-thu-muc-cua-ban

# Khởi tạo Git (làm 1 lần duy nhất cho mỗi dự án)
git init
# → Initialized empty Git repository in ...

Bước 2 — Xem trạng thái, thêm file vào staging, rồi commit:

Terminal quy trình hàng ngày 
# Xem file nào đang thay đổi
git status

# Thêm 1 file vào staging
git add ten_file.py

# Thêm TẤT CẢ file đang thay đổi vào staging
git add .

# Chụp ảnh lưu lại (commit)
git commit -m "Mô tả ngắn về những gì bạn vừa làm"

# Xem lịch sử các lần chụp ảnh
git log --oneline
✏️
Viết message commit tốt: Dùng tiếng Việt hoặc tiếng Anh, mô tả ngắn gọn bạn vừa làm GÌ. Ví dụ: "Thêm bài tập tính BMI", "Sửa lỗi vòng lặp tuần 2".

Ví dụ thực tế — lưu bài tập Python của bạn:

Terminal ví dụ thực tế 
# Tạo thư mục bài tập và vào trong đó
mkdir bai-tap-python
cd bai-tap-python

# Khởi tạo Git
git init

# Sau khi viết code xong, lưu lại lần đầu
git add .
git commit -m "Bài tập tuần 1 - tính BMI"

# Viết thêm bài tập mới, rồi lưu tiếp
git add .
git commit -m "Thêm bài tập tính bảng cửu chương"

# Xem lịch sử
git log --oneline
# a1b2c3d Thêm bài tập tính bảng cửu chương
# f4e5d6c Bài tập tuần 1 - tính BMI

🙈
File .gitignore
Bảo Git "đừng quan tâm đến file này"
▼
Lý thuyết

Có những file bạn không muốn Git lưu lại — ví dụ: file mật khẩu, file tạm thời, thư mục __pycache__ của Python. File .gitignore giúp bạn nói với Git: "hãy bỏ qua những thứ này".

Terminal .gitignore 
# Nội dung file .gitignore:

__pycache__/        # thư mục tự động Python tạo ra
*.pyc               # file compiled của Python
.env                # file chứa mật khẩu, đừng bao giờ commit!
*.log               # file log
⚠️
Lưu ý quan trọng: File .gitignore phải được đặt ngay trong thư mục gốc của dự án (cùng chỗ với thư mục .git).

Tuần 6 · GitHub — Lưu code lên mạng
🌐
Tạo tài khoản GitHub & Repository
Đăng ký · tạo repo mới · hiểu giao diện GitHub
▼
Lý thuyết

GitHub giống như Google Drive nhưng dành riêng cho code. Bạn có thể lưu code lên đó, xem lại lịch sử, và chia sẻ với bạn bè hoặc thầy cô.

Bước 1 — Đăng ký tài khoản:

  • Vào trang github.com
  • Click Sign up → điền email, mật khẩu, tên người dùng
  • Xác nhận email → đăng nhập

Bước 2 — Tạo repository (repo) mới:

  • Click dấu + góc trên phải → New repository
  • Đặt tên repo (ví dụ: bai-tap-python)
  • Chọn Public (công khai) hoặc Private (riêng tư)
  • KHÔNG tick "Add a README file" nếu máy bạn đã có code sẵn
  • Click Create repository
💡
Repository (gọi tắt là repo) = kho chứa một dự án. Mỗi dự án nên có một repo riêng.

🚀
Đẩy code lên GitHub (push)
remote · push · xem code trên GitHub
▼
Lý thuyết

Sau khi tạo repo trên GitHub, bạn cần "nối" thư mục trên máy tính với repo trên GitHub, rồi "đẩy" code lên. Chỉ cần làm một lần.

Terminal lần đầu push lên GitHub 
# 1. Đổi tên nhánh chính thành "main" (chuẩn GitHub)
git branch -M main

# 2. Nối thư mục máy tính với repo GitHub
#    (thay YOUR_USERNAME và YOUR_REPO bằng của bạn)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# 3. Đẩy code lên GitHub lần đầu
git push -u origin main
# → GitHub sẽ hỏi tên đăng nhập và mật khẩu (hoặc token)

Từ lần thứ 2 trở đi, mỗi khi muốn cập nhật code mới lên chỉ cần:

Terminal cập nhật hàng ngày 
# Lưu thay đổi
git add .
git commit -m "Mô tả thay đổi"

# Đẩy lên GitHub
git push
🔑
Nếu GitHub hỏi mật khẩu nhiều lần, hãy dùng Personal Access Token thay vì mật khẩu thường. Vào GitHub → Settings → Developer settings → Personal access tokens → Generate new token.

⬇️
Tải code về máy (clone & pull)
clone · pull · dùng khi chuyển máy tính
▼
Lý thuyết

Nếu bạn muốn tải code từ GitHub về máy tính mới (ví dụ máy tính ở nhà và ở trường), dùng lệnh clone. Nếu code trên GitHub có gì mới và bạn muốn cập nhật về máy, dùng pull.

Terminal 
# Tải một repo từ GitHub về máy (lần đầu dùng máy mới)
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
# → Tạo ra thư mục mới chứa toàn bộ code và lịch sử

# Cập nhật code mới nhất từ GitHub về máy
git pull
# → Dùng khi GitHub có thay đổi mà máy bạn chưa có
🏠
Thói quen tốt: Mỗi khi bắt đầu làm việc, chạy git pull trước để đảm bảo code trên máy là mới nhất. Mỗi khi xong việc, chạy git push để lưu lên GitHub.
